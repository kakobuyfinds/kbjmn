Size, QC photos and shipping

  1. Record measurements. Save the seller’s size chart and units. For tops, compare chest width and body length against a garment that fits. For shoes, check whether the chart lists foot length or insole length.
  2. Review warehouse photos. If QC photos are available for your order, compare the size label, color and visible details with your selected option. Ask for a measurement photo if the fit is unclear.
  3. Compare quotes for the same parcel. Use the same destination, packed dimensions and weight. Record each line’s billable weight, delivery estimate and included services. Compare the item cost, domestic delivery, agent fees, international shipping and any applicable import charges in one currency.

HipoBuy spreadsheet FAQ

Where do the product links go?

Each product name opens its CAFANS detail page. Check the available purchase options there.

Does the listed price include shipping?

The catalog shows indicative item prices. Check the agent’s quote for delivery and other fees.

What should I do if a listing changes?

Recheck the seller, size, color and current price before using a saved link or placing an order.
